# 🔧 Решение проблемы подключения к Obsidian API

## Проблема
API возвращает ошибку `401 Unauthorized` - это значит что API ключ не передаётся правильно.

## ✅ Решение (пошагово)

### Шаг 1: Проверьте настройки плагина в Obsidian

1. Откройте **Obsidian**
2. Перейдите: **Настройки** → **Сторонние плагины** → **Local REST API with MCP** → **⚙️** (шестерёнка)

### Шаг 2: ВАЖНО! Отключите HTTPS

В настройках плагина найдите опцию:
- **"Enable HTTPS"** или **"Use HTTPS"**
- **ВЫКЛЮЧИТЕ её** ❌

Это критически важно! Без этого браузер не сможет подключиться из-за самоподписанного сертификата.

### Шаг 3: Скопируйте API ключ заново

1. В настройках плагина найдите раздел **"API Key"**
2. Нажмите кнопку копирования (или выделите и скопируйте вручную)
3. **Убедитесь что ключ скопировался полностью** (без пробелов в начале/конце)

### Шаг 4: Вставьте ключ в MindFlow

1. Откройте MindFlow
2. Нажмите **⚙️** (Настройки) → вкладка **📝 Obsidian**
3. Вставьте API ключ в поле
4. Нажмите **💾 Сохранить настройки**
5. Нажмите **🔄 Проверить**

### Шаг 5: Перезапустите Obsidian

После изменения настроек:
1. **Полностью закройте Obsidian** (не просто сверните)
2. **Запустите снова**
3. Подождите 10 секунд
4. Попробуйте подключиться снова в MindFlow

## 🔍 Проверка в браузере

Откройте браузер (Chrome/Edge) и перейдите:

```
http://127.0.0.1:27124
```

**Что вы должны увидеть:**

### ✅ Если видите JSON:
```json
{
  "status": "OK",
  "authenticated": true
}
```
**Отлично!** API работает и аутентификация проходит.

### ⚠️ Если видите JSON с `authenticated: false`:
```json
{
  "status": "OK",
  "authenticated": false
}
```
**API работает**, но ключ не передаётся. Проверьте что ключ правильно вставлен в MindFlow.

### ❌ Если видите ошибку подключения:
Плагин не запущен или HTTPS включён. Проверьте настройки плагина.

---

## 🆘 Если ничего не помогает

### Вариант 1: Отключите требование API ключа

В настройках плагина Local REST API найдите опцию:
- **"Require API Key"** или **"Enable Authentication"**
- **ВЫКЛЮЧИТЕ её** ❌

Это менее безопасно, но для локального использования нормально.

### Вариант 2: Используйте обычный плагин

Если плагин "Local REST API with MCP" не работает:
1. Удалите его
2. Установите обычный **"Local REST API"** (без MCP)
3. Автор: coddingtonbear
4. Настройте его (порт 27124, HTTPS выключено)

## 📋 Чек-лист

Перед подключением убедитесь:

- [ ] Obsidian запущен и vault открыт
- [ ] Плагин Local REST API включён (зелёный переключатель)
- [ ] **HTTPS ВЫКЛЮЧЕН** в настройках плагина
- [ ] Порт: 27124
- [ ] API ключ скопирован полностью (без пробелов)
- [ ] API ключ вставлен в MindFlow
- [ ] Obsidian перезапущен после изменений
- [ ] В браузере `http://127.0.0.1:27124` отвечает

---

## 💡 Альтернативное решение

Если интеграция не работает, вы всё равно можете использовать Obsidian ссылки:

1. В MindFlow добавьте название заметки в узел
2. Клик по ссылке откроет заметку через протокол `obsidian://`
3. Это работает **без API** и **без плагина**

Просто укажите путь к vault в настройках для информации.
