# 🖥️ Создание десктопного приложения MindFlow для Windows

Пошаговая инструкция по превращению веб-приложения в устанавливаемую программу Windows.

---

## 📋 Что мы создадим:

- ✅ **MindFlow.exe** — отдельная программа
- ✅ **Setup.exe** — установщик с мастером установки
- ✅ Ярлык на рабочем столе
- ✅ Работа без браузера и Node.js
- ✅ Размер: ~80-100 MB

---

## 🚀 Пошаговая инструкция

### Шаг 1: Откройте package.json

1. Откройте папку проекта
2. Найдите файл **package.json**
3. Откройте его в любом текстовом редакторе (Блокнот, VS Code)

### Шаг 2: Добавьте поле "main"

Найдите первую строку после `{` и добавьте:

```json
{
  "name": "mindflow",
  "version": "1.0.0",
  "main": "electron/main.js",
  ...
}
```

**Важно:** поле `"main"` должно быть на одном уровне с `"name"` и `"version"`.

### Шаг 3: Добавьте скрипты для Electron

Найдите секцию `"scripts"` и добавьте две новые строки:

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "electron:dev": "concurrently \"npm run dev\" \"wait-on http://localhost:5173 && electron .\"",
    "electron:build": "npm run build && electron-builder --win --config electron-builder.yml"
  }
}
```

### Шаг 4: Установите дополнительные пакеты

Откройте командную строку в папке проекта и выполните:

```bash
npm install --save-dev concurrently wait-on
```

Эти пакеты нужны для одновременного запуска Vite и Electron.

### Шаг 5: Проверьте структуру файлов

Убедитесь, что в папке проекта есть:

```
ваша-папка/
├── electron/
│   ├── main.js          ← главный процесс Electron
│   ├── preload.js       ← мост безопасности
│   └── icon.png         ← иконка приложения (512x512)
├── src/                 ← исходный код React
├── dist/                ← собранный веб-проект (появится после build)
├── package.json         ← конфигурация проекта
├── electron-builder.yml ← настройки сборки
├── build-desktop.bat    ← скрипт сборки
└── start-desktop.bat    ← запуск в режиме разработки
```

### Шаг 6: Запуск в режиме разработки

**Вариант А: Через скрипт**

Дважды кликните на **start-desktop.bat**

**Вариант Б: Вручную**

Откройте командную строку в папке проекта и выполните:

```bash
npm run electron:dev
```

Откроется десктопное окно с вашим приложением! 🎉

### Шаг 7: Сборка установщика

**Вариант А: Через скрипт**

Дважды кликните на **build-desktop.bat**

**Вариант Б: Вручную**

```bash
npm run electron:build
```

Процесс сборки займёт 5-15 минут. После завершения:

1. В папке проекта появится папка **release/**
2. Внутри будет файл **MindFlow-Setup-1.0.0.exe**
3. Запустите его для установки приложения

---

## 📦 Что происходит при сборке:

1. **Vite** собирает React-приложение в папку `dist/`
2. **Electron** упаковывает `dist/` + `electron/` в единый bundle
3. **electron-builder** создаёт установщик `.exe`

## 🔧 Решение проблем

### Проблема: "Cannot find module 'electron'"

**Решение:**
```bash
npm install
```

### Проблема: "Application entry point could not be inferred"

**Решение:** Убедитесь, что в `package.json` есть поле `"main": "electron/main.js"`

### Проблема: Ошибка при сборке "Cannot find module 'concurrently'"

**Решение:**
```bash
npm install --save-dev concurrently wait-on
```

### Проблема: Антивирус удаляет .exe файл

**Решение:**
1. Добавьте папку проекта в исключения антивируса
2. Или временно отключите антивирус на время сборки

### Проблема: Большой размер установщика (>150 MB)

**Решение:** Это нормально для Electron. Можно оптимизировать:
- Удалить неиспользуемые зависимости
- Использовать `electron-builder --win --x64` только для 64-bit

## 📤 Распространение приложения

### Вариант 1: Локальная установка

1. Скопируйте файл **MindFlow-Setup-1.0.0.exe**
2. Отправьте друзьям/коллегам
3. Они запускают и устанавливают

### Вариант 2: Портативная версия

Добавьте в `electron-builder.yml`:

```yaml
win:
  target:
    - target: portable
      arch:
        - x64
```

Пересоберите — получите **MindFlow-1.0.0.exe** (без установки, работает из любой папки).

### Вариант 3: Публикация в интернете

1. Загрузите `MindFlow-Setup-1.0.0.exe` на:
   - GitHub Releases
   - Google Drive
   - Яндекс.Диск
2. Поделитесь ссылкой
