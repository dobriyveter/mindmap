# 📥 Как скачать и запустить проект

## 🔽 Способ 1: Скачать файлы проекта

### Вариант А: Через интерфейс (если доступен)

Если вы используете онлайн-среду разработки:
1. Найдите кнопку **"Download"** или **"Скачать"** в интерфейсе
2. Скачается ZIP-архив с проектом
3. Распакуйте его в удобную папку, например: `C:\MindFlow`

### Вариант Б: Скопировать файлы вручную

Создайте папку проекта и скопируйте в неё все файлы из текущей среды:

**Структура папок:**

## 💻 Способ 2: Запуск через Visual Studio Code

**Visual Studio Code** (VS Code) — это бесплатный редактор кода от Microsoft, идеально подходит для веб-проектов.

⚠️ **Важно:** Не путайте с **Visual Studio** (IDE для C#/.NET) — это разные программы!

### Шаг 1: Установите Visual Studio Code

1. Перейдите на сайт: **https://code.visualstudio.com/**
2. Скачайте версию для Windows
3. Установите (просто нажимайте Next)

### Шаг 2: Откройте проект в VS Code

1. Запустите VS Code
2. Нажмите **File** → **Open Folder** (или `Ctrl + K, Ctrl + O`)
3. Выберите папку проекта (например, `C:\MindFlow`)
4. Нажмите **Выбор папки**

### Шаг 3: Откройте терминал в VS Code

1. Нажмите **Terminal** → **New Terminal** (или `Ctrl + ~`)
2. Внизу появится терминал — он уже находится в папке проекта

### Шаг 4: Установите зависимости

В терминале VS Code введите:
```bash
npm install
```

Дождитесь окончания установки (2-5 минут).

### Шаг 5: Запустите приложение

В терминале введите:
```bash
npm run dev
```

Откройте браузер и перейдите по адресу: **http://localhost:5173/**

✅ **Готово!** Приложение запущено!

## 🎨 Рекомендуемые расширения для VS Code

Для удобной работы установите эти расширения:

1. **ES7+ React/Redux/React-Native snippets** — сниппеты для React
2. **Tailwind CSS IntelliSense** — автодополнение для Tailwind
3. **TypeScript Importer** — автоматический импорт
4. **Prettier** — форматирование кода
5. **ESLint** — проверка ошибок

### Как установить расширения:

1. Нажмите на иконку **Extensions** слева (или `Ctrl + Shift + X`)
2. Введите название расширения в поиске
3. Нажмите **Install**

## 🚀 Альтернатива: Visual Studio 2022

Если у вас установлен **Visual Studio 2022** (не Code), можно открыть проект и в нём:

### Шаг 1: Откройте папку проекта

1. Запустите Visual Studio 2022
2. Нажмите **File** → **Open** → **Folder**
3. Выберите папку проекта

### Шаг 2: Откройте терминал

1. Нажмите **View** → **Terminal** (или `Ctrl + ~`)
2. Терминал откроется в папке проекта

### Шаг 3: Установите зависимости и запустите

```bash
npm install
npm run dev
```

⚠️ **Примечание:** Visual Studio 2022 не имеет встроенной поддержки Node.js из коробки, но терминал работает. Для полноценной работы лучше использовать **VS Code**.

## 📦 Создание ярлыка для быстрого запуска

### Создайте файл `start.bat`

1. В папке проекта создайте текстовый файл
2. Переименуйте его в `start.bat`
3. Откройте в Блокноте и вставьте:

```bat
@echo off
title MindFlow
echo.
echo ========================================
echo   Запуск MindFlow...
echo ========================================
echo.
echo Приложение будет доступно по адресу:
echo http://localhost:5173/
echo.
echo Для остановки нажмите Ctrl+C
echo.
echo ========================================
echo.
npm run dev
pause
```

4. Сохраните файл

### Создайте ярлык на рабочем столе

1. Правый клик на `start.bat`
2. **Отправить** → **Рабочий стол (создать ярлык)**
3. Теперь можно запускать двойным кликом!

## ❓ Частые вопросы

### В: Можно ли использовать обычный Visual Studio (не Code)?
**О:** Да, но VS Code удобнее для веб-разработки. Visual Studio 2022 тоже работает через терминал.

### В: Какой редактор лучше использовать?
**О:** **Visual Studio Code** — бесплатный, лёгкий, с отличной поддержкой React/TypeScript.

### В: Можно ли открыть проект в WebStorm?
**О:** Да! WebStorm отлично подходит. Просто откройте папку проекта и выполните `npm install` + `npm run dev`.

### В: Нужен ли интернет для работы?
**О:** Интернет нужен только для:
- Установки зависимостей (`npm install`)
- Загрузки изображений по URL
- Интеграции с Obsidian (опционально)

После установки приложение работает офлайн.

### В: Где хранятся данные карт?
**О:** В localStorage браузера. Для переноса на другой компьютер используйте экспорт/импорт JSON.
