# 🧠 MindFlow — Инструкция по запуску

Пошаговое руководство по установке и запуску приложения для создания ментальных карт.

---

## 📋 Что вам понадобится

- **Компьютер** с Windows 10/11
- **Интернет** для установки инструментов
- **5-10 минут** свободного времени
- **Obsidian** (опционально, для интеграции)

---

## 🚀 Шаг 1: Установка Node.js

Node.js — это среда для запуска JavaScript-приложений.

### 1.1. Скачайте Node.js

1. Откройте браузер и перейдите на сайт: **https://nodejs.org/**
2. Скачайте версию **LTS** (Long Term Support) — это стабильная версия
   - Кнопка будет зелёная, слева
   - Файл называется примерно: `node-v20.x.x-x64.msi`

### 1.2. Установите Node.js

1. Запустите скачанный файл `.msi`
2. Нажимайте **Next** на всех экранах
3. Примите лицензионное соглашение
4. Оставьте путь установки по умолчанию
5. Нажмите **Install**
6. Дождитесь окончания установки
7. Нажмите **Finish**

### 1.3. Проверьте установку

1. Нажмите `Win + R` на клавиатуре
2. Введите `cmd` и нажмите Enter
3. В открывшемся окне введите:
   ```
   node --version
   ```
4. Должно появиться что-то вроде: `v20.11.0`
5. Введите ещё:
   ```
   npm --version
   ```
6. Должно появиться: `10.2.4` (или похожее)

✅ **Если обе команды показали версии — Node.js установлен правильно!**

❌ **Если команды не работают** — перезагрузите компьютер и попробуйте снова.

---

## 📁 Шаг 2: Подготовка проекта

### Вариант А: Если у вас уже есть папка проекта

Просто перейдите к Шагу 3.

### Вариант Б: Если нужно создать проект с нуля

1. Создайте папку, например: `C:\MindFlow`
2. Скопируйте в неё все файлы проекта
3. Убедитесь, что в папке есть файл `package.json`

---

## ⚙️ Шаг 3: Установка зависимостей

1. Откройте папку проекта в Проводнике
2. В адресной строке Проводника введите `cmd` и нажмите Enter
   - Это откроет командную строку прямо в папке проекта
3. Введите команду:
   ```
   npm install
   ```
4. Дождитесь окончания установки (2-5 минут)
   - Появится много текста — это нормально
   - В конце должно быть что-то вроде: `added 250 packages in 45s`

✅ **Если в конце нет красных ошибок — установка прошла успешно!**

❌ **Если есть ошибки** — проверьте интернет-соединение и попробуйте снова.

---

## 🎬 Шаг 4: Запуск приложения (режим разработки)

1. В той же командной строке введите:
   ```
   npm run dev
   ```
2. Дождитесь сообщения типа:
   ```
   VITE v5.0.0  ready in 500 ms
   ➜  Local:   http://localhost:5173/
   ```
3. Откройте браузер и перейдите по адресу: **http://localhost:5173/**
4. Вы увидите приложение MindFlow! 🎉

### Остановка приложения

Чтобы остановить сервер, в командной строке нажмите: `Ctrl + C`

---

## 📦 Шаг 5: Сборка для использования (опционально)

Если хотите использовать приложение без запуска сервера:

1. В командной строке введите:
   ```
   npm run build
   ```
2. Дождитесь окончания сборки (30-60 секунд)
3. В папке проекта появится папка `dist`
4. Откройте файл `dist/index.html` в браузере

---

## 🪟 Шаг 6: Создание ярлыка для быстрого запуска (опционально)

### 6.1. Создайте файл запуска

1. В папке проекта создайте текстовый файл
2. Переименуйте его в `start.bat`
3. Откройте его в Блокноте и вставьте:
   ```bat
   @echo off
   echo Запуск MindFlow...
   echo.
   echo Приложение будет доступно по адресу: http://localhost:5173/
   echo.
   echo Для остановки нажмите Ctrl+C
   echo.
   npm run dev
   pause
   ```
4. Сохраните файл

### 6.2. Создайте ярлык

1. Правый клик на `start.bat` → **Отправить** → **Рабочий стол (создать ярлык)**
2. Теперь можно запускать приложение двойным кликом на ярлык!

---

## 📝 Шаг 7: Интеграция с Obsidian (опционально)

Если хотите связывать узлы с заметками Obsidian:

### 7.1. Простой способ (без плагина)

1. Откройте MindFlow
2. Нажмите ⚙️ (Настройки) → вкладка **Obsidian**
3. Укажите путь к вашему хранилищу Obsidian, например:
   ```
   C:\Users\ВашеИмя\Documents\MyVault
   ```
4. Нажмите **Сохранить**
5. Теперь в боковой панели узла можно добавлять названия заметок
6. Клик по заметке откроет её в Obsidian

### 7.2. Продвинутый способ (с поиском заметок)

1. Откройте Obsidian
2. Перейдите: **Настройки** → **Сторонние плагины**
3. Отключите **Безопасный режим** (если спрашивает подтверждение — согласитесь)
4. Нажмите **Обзор** и найдите плагин: **Local REST API**
5. Установите и включите плагин
6. В настройках плагина скопируйте **API Key**
7. В MindFlow → Настройки → Obsidian → проверьте подключение
8. Теперь можно искать заметки прямо из MindFlow!

## 🎮 Шаг 8: Основные горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Двойной клик` на пустом месте | Создать новый узел |
| `Двойной клик` на узле | Редактировать текст |
| `Tab` | Создать дочерний узел (со стрелкой) |
| `Enter` | Создать соседний узел |
| `Delete` | Удалить выделенный узел |
| `Ctrl + Z` | Отменить действие |
| `Ctrl + Y` | Повторить действие |
| `Ctrl + D` | Дублировать узел |
| `Ctrl + клик` по узлам | Выделить несколько для связи |
| `Колёсико мыши` | Масштабирование |
| `Перетаскивание` пустого места | Перемещение по карте |
| `ПКМ` на узле | Контекстное меню |

## 💾 Шаг 9: Сохранение и загрузка карт

### Автосохранение
- Карта автоматически сохраняется каждые 30 секунд
- Данные хранятся в браузере (localStorage)

### Экспорт карты
1. Нажмите 📤 в тулбаре
2. Выберите формат:
   - **JSON** — для импорта обратно
   - **SVG** — векторная картинка
   - **Markdown** — текстовый формат

### Импорт карты
1. Нажмите 📥 в тулбаре
2. Выберите JSON-файл карты

### Облачная синхронизация
- Экспортируйте карту в JSON
- Сохраните файл в облако (Google Drive, Dropbox, OneDrive)
- На другом компьютере импортируйте файл

## ❓ Решение проблем

### Проблема: `npm` не распознаётся как команда
**Решение:** Переустановите Node.js и перезагрузите компьютер.

### Проблема: Ошибки при `npm install`
**Решение:**
1. Удалите папку `node_modules` (если есть)
2. Удалите файл `package-lock.json` (если есть)
3. Снова выполните `npm install`

### Проблема: Порт 5173 уже занят
**Решение:** Закройте другие приложения или используйте другой порт:
```
npm run dev -- --port 3000
```

### Проблема: Страница не открывается в браузере
**Решение:**
1. Проверьте, что сервер запущен (в командной строке должно быть сообщение)
2. Попробуйте другой браузер
3. Очистите кэш браузера (Ctrl + Shift + Delete)

### Проблема: Связи между узлами не отображаются
**Решение:**
1. Убедитесь, что создали хотя бы 2 узла
2. Используйте кнопку 🔗 или `Ctrl+клик` по узлам
3. Обновите страницу (F5)
